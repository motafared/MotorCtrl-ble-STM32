MotorCtrl — Connections to the STM32 Board

STM32WB55 carrier board (Phase 2). One connection group per diagram. Pins mirror Core/Inc/main.h; source: motorctrl.py (SKiDL).

Board MCU module: WeAct STM32WB55CGU6 (U2). Logic = 3.3 V; motors run on +12 V.

1. STM32 ↔ Motors

Two 4-wire BLDC motors on connectors J3 (M1) and J4 (M2). PWM drives the motor; the tacho returns one pulse train per revolution.

   Motor M1  (J3, 4-wire)            STM32WB55 board (U2)
   ┌─────────────────────┐          ┌──────────────────────────┐
   │ +12V   (J3.2)       ├── +12V ───┤ +12V rail                │
   │ GND    (J3.1)       ├── GND  ───┤ GND                      │
   │ PWM    (J3.3)       ├◄──────────┤ PA0   M1_PWM             │ TIM2_CH1
   │ Tacho  (J3.4)       ├──────────►┤ PA8   M1_TACH            │ TIM1_CH1
   └─────────────────────┘          └──────────────────────────┘

   Motor M2  (J4, 4-wire)            STM32WB55 board (U2)
   ┌─────────────────────┐          ┌──────────────────────────┐
   │ +12V   (J4.2)       ├── +12V ───┤ +12V rail                │
   │ GND    (J4.1)       ├── GND  ───┤ GND                      │
   │ PWM    (J4.3)       ├◄──────────┤ PA1   M2_PWM             │ TIM2_CH2
   │ Tacho  (J4.4)       ├──────────►┤ PA9   M2_TACH            │ TIM1_CH2
   └─────────────────────┘          └──────────────────────────┘

Each tacho line has a pull-up to +3V3 on the board: R1 (M1), R2 (M2). PWM = 20 kHz (TIM2); tacho = timer input-capture (TIM1).

2. STM32 ↔ Buttons

Three momentary push-buttons. Active-HIGH: the switch connects the MCU pin to +3V3 when pressed; the MCU's internal pull-down holds the pin low when released (firmware sets GPIO_PULLDOWN, so no external pull-up resistor is needed).

   Push-buttons                      STM32WB55 board (U2)
   ┌─────────────────────┐          ┌──────────────────────────┐
   │ START   SW1 ─[R6]───├──────────►┤ PA3   BTN_START          │ EXTI3  rising (press)
   │ STOP    SW2 ─[R7]───├──────────►┤ PA2   BTN_STOP           │ EXTI2  rising (press)
   │ CONT    SW3 ─[R8]───├──────────►┤ PA4   BTN_CONTINUE       │ EXTI4  both edges
   │ (common → +3V3)     │          │   (internal pull-down ON) │
   └─────────────────────┘          └──────────────────────────┘

Idle = LOW (held by the MCU internal pull-down); pressed = HIGH (pin tied to +3V3 through series R6/R7/R8). Optional debounce cap C7/C8/C9 → GND (firmware also debounces 50 ms). START/STOP fire on the rising (press) edge; CONTINUE fires on both edges — runs while held, stops on release.
⚠ Changed from the earlier active-low design: the button common now goes to +3V3 (was GND) and the external pull-ups R3/R4/R5 are removed (replaced by the MCU's internal pull-down). The SKiDL source motorctrl.py must be updated to match. Source of truth: Core/Src/main.c → MX_GPIO_Init (PA2/PA3 GPIO_MODE_IT_RISING, PA4 GPIO_MODE_IT_RISING_FALLING, all GPIO_PULLDOWN).

3. STM32 ↔ Status LED

   STM32WB55 board (U2)              Status LED
   ┌──────────────────────────┐     ┌──────────────┐
   │ PE4   LED_DRIVE ─[R9 1k]──├────►┤ D2 anode     │
   │ GND ──────────────────────├─────┤ D2 cathode   │
   └──────────────────────────┘     └──────────────┘

PE4 high → LED on (motors running / heartbeat). R9 = 1 kΩ series.

4. STM32 ↔ SWD programmer

5-pin header J5 for flashing/debug (ST-LINK).

   SWD header (J5, 1×5)              STM32WB55 board (U2)
   ┌─────────────────────┐          ┌──────────────────────────┐
   │ +3V3   (J5.1)       ├── 3V3 ────┤ +3V3                     │
   │ SWDIO  (J5.2)       ├──────────►┤ PA13  SWDIO              │
   │ SWCLK  (J5.3)       ├──────────►┤ PA14  SWCLK              │
   │ NRST   (J5.4)       ├──────────►┤ NRST                     │
   │ GND    (J5.5)       ├── GND ────┤ GND                      │
   └─────────────────────┘          └──────────────────────────┘

5. Power input

12 V DC barrel jack → reverse-polarity Schottky → on-board regulator.

   12 V DC jack (J1)        Board power stage                  Rails
   ┌─────────────────┐      ┌──────────────────────────┐      ┌──────────┐
   │ +12V   (J1.1)   ├─ D1 ─┤ Schottky → +12V rail       ├────►│ +12V     │
   │                 │      │ AMS1117 (U1): 12V → 3.3V   ├────►│ +3V3     │
   │ GND    (J1.2)   ├──────┤ common ground              ├────►│ GND      │
   └─────────────────┘      └──────────────────────────┘      └──────────┘

+12V rail → motors (J3.2/J4.2) + decoupling. +3V3 → U2, pull-ups, SWD.
